Talk face to face, peer to peer.

AtomConnect is a browser messenger with HD video, voice, chat, file transfer and screen sharing. Open source and self-hosted on your own Cloudflare account: you run the signaling and TURN, so your calls stay yours.

Everything a call needs

Media flows directly between browsers, encrypted end to end by WebRTC. The server only introduces the two sides.

Adaptive video

Resolution and bitrate adjust to bandwidth and screen size, with a live quality indicator on the picture.

Clear voice

Opus audio with echo cancellation. Pick your microphone and speaker on the fly, even mid-call.

Chat and files

Messages and file transfer over a direct data channel, with image previews right in the conversation.

Screen sharing

Share your desktop with one click when you need to show, not tell.

Mobile first

Touch-friendly controls, front camera by default, and a camera flip button on phones.

Private by design

DTLS-SRTP encryption, no accounts, and sessions that end when everyone hangs up.

Architecture

A thin signaling plane on the edge, a direct media plane between browsers.

Signaling

WebSocket at /ws?room=. One Durable Object per room relays offer, answer and ICE, caps the room at 2 peers, keeps the session across reconnects, and ends it on hangup or after 2 minutes empty.

NAT traversal

ICE with STUN, plus short-lived TURN credentials minted per request at /ice via the Cloudflare Realtime API. Roughly 10–20% of connections need the relay.

Adaptive quality

Built-in congestion control (transport-cc) plus RTCRtpSender.setParameters(): scaleResolutionDownBy and maxBitrate follow receiver viewport and link quality.

Data channel

A reliable RTCDataChannel carries chat, chunked file transfer and viewport hints, all inside the same DTLS session.

Session registry

A registry Durable Object records session history and grades, exposed through a token-protected admin API and dashboard.

Client

A single static index.html with no build step, served as Workers assets, with a version check that prompts open tabs to reload.

Self-host in minutes

Requires Node.js and a Cloudflare account. Secrets stay in Wrangler, never in the repo.

⬇ Download ZIP Clone on GitHub 
git clone https://github.com/alexander-uspenskiy/AtomConnect.git
cd AtomConnect/server
npm install
cp wrangler.example.jsonc wrangler.jsonc   # add TURN_KEY_ID, CF_ACCOUNT_ID
npx wrangler login
npx wrangler secret put TURN_API_TOKEN
npx wrangler secret put ADMIN_TOKEN
npm run deploy                              # signaling Worker
cd ../client && npx wrangler deploy         # static client
